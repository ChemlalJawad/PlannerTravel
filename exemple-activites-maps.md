# Guide d'utilisation : Activités avec Google Maps

## Comment ajouter des activités sur la carte

### Étape 1 : Trouver l'adresse sur Google Maps

1. Ouvrez [Google Maps](https://maps.google.com)
2. Recherchez le lieu (restaurant, temple, attraction, etc.)
3. Cliquez sur le lieu pour voir ses détails
4. Cliquez sur "Partager" ou copiez l'URL directement depuis la barre d'adresse

### Étape 2 : Ajouter l'activité dans TravelPlanner

1. Allez dans l'onglet **Planning** (📅)
2. Cliquez sur **"Ajouter activité"**
3. Remplissez les informations :
   - **Titre** : Nom du lieu
   - **Description** : Détails sur la visite
   - **Catégorie** : Choisir le type (Restaurant, Visite, Shopping, etc.)
   - **🗺️ Lien Google Maps** : Collez l'URL Google Maps ici
4. Enregistrez l'activité

### Étape 3 : Voir sur la carte

1. Allez dans l'onglet **Carte** (🗺️)
2. Vous verrez :
   - **Gros marqueurs** (rouge/bleu) = Villes/destinations principales
   - **Petits points colorés** = Activités spécifiques
     - 🟠 Orange = Restaurants
     - 🟢 Vert = Visites touristiques
     - 🩷 Rose = Shopping
     - 🟣 Violet = Hébergement
     - 🔵 Bleu = Transport

3. Cliquez sur un marqueur pour voir les détails et le bouton "Ouvrir dans Google Maps"

## Exemples d'URLs Google Maps supportées

### Format 1 : URL avec coordonnées @
```
https://www.google.com/maps/place/Temple+of+Heaven/@39.8822,116.4066,15z
```

### Format 2 : URL courte
```
https://maps.app.goo.gl/abc123
```

### Format 3 : URL avec ?q=
```
https://maps.google.com/?q=39.9042,116.4074
```

## Conseils

1. **Vérifiez les URL** : Assurez-vous que l'URL contient des coordonnées GPS (lat, lng)
2. **Catégories** : Utilisez la bonne catégorie pour avoir la bonne couleur sur la carte
3. **Description** : Ajoutez des détails utiles (horaires, prix, spécialités, etc.)
4. **Mise à jour** : Vous pouvez modifier une activité existante pour ajouter/changer l'URL

## Légende de la carte

- 🔴 **Grand marqueur rouge** = Destination en Chine
- 🔵 **Grand marqueur bleu** = Destination au Japon
- 🟣 **Ligne violette en pointillé** = Itinéraire de voyage
- 🟠 **Petit point orange** = Restaurant
- 🟢 **Petit point vert** = Visite/attraction
- 🩷 **Petit point rose** = Shopping
- 🟣 **Petit point violet** = Hébergement
- 🔵 **Petit point bleu** = Transport
